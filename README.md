# RupeeRakshak AI 🛡️

An AI-powered financial fraud awareness application.

## Features
- Suspicious financial message detection
- Risk score calculation
- Fraud warning indicators
- Financial safety recommendations

## Technologies
- Python
- Streamlit

## How to run

Install dependencies:

pip install -r requirements.txt

Run application:

streamlit run app.py
